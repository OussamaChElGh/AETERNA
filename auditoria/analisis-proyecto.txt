5. TIPOS DE ARTÍCULO (ArticleType)
================================================================================

  conceptual      — Comprender conceptos, principios, modelos
  methodological  — Enseñar forma de pensar, investigar, modelizar
  procedural      — Enseñar procedimiento reproducible
  problem_solving — Resolver problemas y desarrollar razonamiento
  experimental    — Experimentación, observación, medición
  simulation      — Simulación o entorno interactivo
  synthesis       — Integrar, relacionar, consolidar conocimientos

  Cada tipo tiene expectativas de capas (inicio/intermedio/avanzado),
  total de ejercicios recomendado y requerimiento de interactividad.

12. MAPA DE CAPAS (Layer Naming)
================================================================================

  En el contexto Aeterna, los 3 niveles se mapean así:

    principiante  ←→  fundamentos, capa1, inicio
    intermedio    ←→  profundizacion, exegesis, capa2
    avanzado      ←→  frontera, capa3

  Metadatos visuales de capa:

    principiante: { label: "CAPA I: FUNDAMENTOS", code: "CAPA 01", icon: Compass }
    intermedio:   { label: "CAPA II: EXÉGESIS",   code: "CAPA 02", icon: BookOpen }
    avanzado:     { label: "CAPA III: FRONTERA",  code: "CAPA 03", icon: ShieldCheck }

20. SISTEMA DE DISEÑO Y PATRONES UI
================================================================================

  Colores:
    Primary:    #D4AF37 / #8B6914 (brand-gold)

    • Badge: px-3 py-1.5 rounded-lg border text-[10px] font-mono font-bold uppercase
    • Botón gold: bg-brand-gold text-brand-ink hover:bg-black hover:text-brand-gold
    • Progreso: h-2 bg-black/5 rounded-full overflow-hidden
    • Modal: fixed inset-0 bg-black/60 backdrop-blur-md z-[100]
    • Drawer: fixed top-0 right-0 bottom-0 w-80 md:w-96 con spring animation
    • Score circular: SVG circle con strokeDasharray + animación

  Animaciones:
    • motion/react (framer-motion)
    • AnimatePresence para entradas/salidas
    • spring para drawers, fade para modales
    • scale para notificaciones toast
